Cardano governance metadata (`*.jsonld`) for Suzhou Capital, plus a small standalone web tool.

## Weekly Project Tracker

`tracker/index.html` is a single-file, no-build weekly project tracker. Open it in a browser or serve the folder with any static host (e.g. GitHub Pages).

- **Workflow board**: Backlog → To do → In progress → Review → Done. Drag cards between columns or use the ‹ › buttons.
- **Mon–Sun planner**: the same tasks laid out by due day, with today highlighted. Drag to reschedule.
- **ISO week navigation**: each task belongs to a week (e.g. `2026-W40`); step back and forward with ← →.
- **Summary**: points-based progress, stage breakdown, per-project progress and a "needs attention" list (late, high priority, waiting for review, carried over, unowned).
- **Weekly review**: wins, blockers and next week's focus, saved per week.
- **Roll over**: moves every unfinished task into next week and counts how many times it has been carried.
- **Backup / restore**: copy the data as JSON or load a backup file.

Data is stored in the browser's `localStorage`. Keyboard: `n` new task, `Alt+←/→` change week.
